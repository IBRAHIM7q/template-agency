Introduction

Thank you for purchasing our Creative Agency Template! This documentation will guide you through the process of customizing the template to fit your needs. The template is built with HTML, CSS, and JavaScript, making it easy to modify without requiring advanced programming knowledge.

Note: This template requires a web server to run properly. You cannot simply open the HTML files directly in a browser for all features to work correctly.

File Structure

The template has the following file structure:

├── index.html              # Main homepage
├── css/

│   └── main.js            # Main JavaScript file

Customization

Changing Content

To change the content of the template, you need to edit the HTML files. Here's how to modify different sections:

Header and Navigation

To change the logo and navigation menu, edit the header section in each HTML file:

<!-- Header & Navigation -->
<header>
    <div class="container">
        <div class="logo">
            <a href="#">Name</a>  <!-- Change "Name" to your company name -->
        </div>
        <nav>
            <ul class="main-menu">
                <li><a href="#home" class="active">Home</a></li>
                <!-- Add or remove menu items as needed -->
            </ul>
        </nav>
    </div>
</header>

Hero Section

To change the hero section content, locate the hero section in index.html:

<section id="home" class="hero">
    <div class="hero-content">
        <h1 class="animate-text">We are <span class="highlight">Name</span></h1>  <!-- Change "Name" -->
        <h2 class="animate-text delay-1">Creative Digital Agency</h2>  <!-- Change tagline -->
        <p class="animate-text delay-2">We create unique digital experiences that excite and inspire.</p>  <!-- Change description -->
    </div>
</section>

About Section

To change the about section content, find the about section in index.html:

<section id="about" class="about">
    <div class="container">
        <div class="section-header">
            <h2>About Us</h2>
            <p>Learn more about our agency</p>  <!-- Change subtitle -->
        </div>
        <div class="about-content">
            <div class="about-text">
                <h3>We are a creative agency with a passion for design</h3>  <!-- Change heading -->
                <p>Since 2010, we've been helping businesses...</p>  <!-- Change paragraph -->
            </div>
        </div>
    </div>
</section>

Follow the same pattern to edit other sections like Services, Portfolio, Team, Testimonials, and Contact.

Footer

To change the footer content, locate the footer section in each HTML file:

<footer>
    <div class="container">
        <div class="footer-content">
            <!-- Edit footer columns as needed -->
        </div>
        <div class="footer-bottom">
            <p>© 2025 Name Creative Agency. All rights reserved.</p>  <!-- Update copyright info -->
        </div>
    </div>
</footer>

Changing Colors

The template uses CSS variables for colors, making it easy to change the color scheme. Open the css/style.css file and locate the root variables at the top:

:root {
    --primary-color: #6e42ff;
    --primary-gradient: linear-gradient(135deg, #6e42ff, #00d4ff);
    --secondary-color: #ff4d94;
    --secondary-gradient: linear-gradient(135deg, #ff4d94, #ff9b4d);
    --accent-color: #00f7c3;
    --dark-color: #0a0a14;
    --darker-color: #05050a;
    --light-color: #f5f5f5;
    --gray-color: #888888;
    --text-color: #ffffff;
    /* ... other variables ... */
}

Change these color values to match your brand colors. All elements using these variables will automatically update.

Changing Images

To replace images, prepare your new images and place them in the images/ folder. Then update the image paths in the HTML files:

<img src="images/your-new-image.jpg" alt="Description of image">

Note: For best performance, optimize your images before adding them to the template. Use SVG format for icons and logos when possible.

Background Images

Some background images are set in the CSS. To change these, locate the relevant CSS rules in style.css and update the image paths:

.hero-background {
    background-image: url('../images/hero-bg.jpg.svg');
    /* ... other properties ... */
}

Changing Fonts

The template uses Google Fonts. To change the fonts, first add your preferred Google Fonts link to the <head> section of each HTML file:

<link href="https://fonts.googleapis.com/css2?family=Your+Font+Name:wght@400;700&display=swap" rel="stylesheet">

Then update the font variables in the css/style.css file:

:root {
    /* ... other variables ... */
    --body-font: 'Your Font Name', sans-serif;
    --heading-font: 'Your Heading Font', sans-serif;
    /* ... other variables ... */
}

Adding New Pages

To add a new page to the template:

  1. Copy an existing HTML file that is closest to what you want to create (e.g., copy a project page to create a new project page).
  2. Rename the file to match your new page's purpose.
  3. Update the content, title, and meta tags.
  4. Add a link to the new page in the navigation menu or relevant sections.
<!-- Example of adding a new page to navigation -->
<ul class="main-menu">
    <li><a href="index.html">Home</a></li>
    <li><a href="your-new-page.html">Your New Page</a></li>
    <!-- ... other menu items ... -->
</ul>

Setting Up the Contact Form

The contact form in the template is set up for demonstration purposes only. To make it functional, you need to connect it to a backend service or use a form submission service.

Option 1: Using a Form Submission Service

Services like Formspree, Netlify Forms, or FormSubmit allow you to set up form submissions without backend code:

<form id="contactForm" action="https://formspree.io/your-email@example.com" method="POST">
    <!-- ... form fields ... -->
</form>

Option 2: Custom Backend

If you have a backend server, modify the JavaScript in js/main.js to handle form submission:

// Find the form submission code in main.js and update it
if (contactForm) {
    contactForm.addEventListener('submit', function(e) {
        e.preventDefault();
        
        // Get form data
        const formData = new FormData(contactForm);
        
        // Send data to your server
        fetch('your-server-endpoint', {
            method: 'POST',
            body: formData
        })
        .then(response => response.json())
        .then(data => {
            alert('Thank you for your message! We will get back to you soon.');
            contactForm.reset();
        })
        .catch(error => {
            console.error('Error:', error);
            alert('There was an error sending your message. Please try again.');
        });
    });
}

SEO Optimization

To optimize the template for search engines:

  1. Update the title tags in each HTML file to include relevant keywords:
    2. <title>Your Company Name - Specific Service or Page</title>
  2. Add meta description tags to each page:
    3. <meta name="description" content="A compelling description of your page content with relevant keywords.">
  3. Use semantic HTML elements (the template already uses these).
  4. Optimize image alt attributes:
    5. <img src="images/your-image.jpg" alt="Descriptive text with keywords">
  5. Add structured data if relevant to your business.

Troubleshooting

Common Issues

Images Not Loading

If images are not loading, check:

  • Image paths are correct and match the file structure
  • Image files exist in the specified location
  • File permissions allow the web server to access the images

JavaScript Features Not Working

If JavaScript features like the slider or form validation are not working:

  • Check the browser console for errors
  • Verify that the main.js file is properly linked in the HTML
  • Ensure you're viewing the site through a web server, not as local files

Responsive Design Issues

If the site doesn't look right on mobile devices:

  • Make sure the viewport meta tag is present in the head section
  • Check for any CSS overrides that might be affecting responsive behavior
  • Test on multiple devices and browsers

Important: Always back up your files before making significant changes to the template.
